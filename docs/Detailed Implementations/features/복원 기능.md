# 창 크기 영구 저장/복원 기능

## Context

사용자가 창을 리사이즈하면 그 크기를 `user_settings.json`에 저장하고,

다음 실행 시 해당 크기로 창을 복원한다.

메인메뉴·세팅·인게임 모두 동일한 물리 창 크기를 공유하므로 어떤 상태에서 리사이즈해도 저장된다.

BGM 설정(On/Off, 볼륨)도 함께 저장한다 (기존에 미저장).

---

## 아키텍처

```
[OS 리사이즈] → SDL_WINDOWEVENT_SIZE_CHANGED → Window::Update()

                  → m_resize_callback 호출

                  → (main.cpp 등록) Settings::s_window_size 갱신 + SaveUserSettings()



[앱 시작] main.cpp → engine.Start() → LoadUserSettings() → ForceResize(s_window_size) → PushState<Splash>
```

**engine → game 의존 없음**: Window에 `ResizeCallback` 훅만 추가, main.cpp에서 게임 코드로 등록.

---

## 영향 파일

| 파일 | 변경 |

|------|------|

| `source/Engine/Window.h` | `ResizeCallback` 타입 + `SetResizeCallback()` 선언 + private 멤버 추가 |

| `source/Engine/Window.cpp` | `SDL_WINDOWEVENT_SIZE_CHANGED` 처리 후 resize callback 호출 + `SetResizeCallback` 구현 |

| `source/Game/Settings.h` | `static Math::ivec2 s_window_size`, `LoadUserSettings()`, `SaveUserSettings()` 추가 |

| `source/Game/Settings.cpp` | 위 메서드 구현 (nlohmann/json), BGM 변경 시 자동 저장 |

| `source/main.cpp` | 시작 시 로드·리사이즈·resize callback 등록 |

| `source/Game/MainMenu.cpp` | `ForceResize`에 `Settings::s_window_size` 사용 |

## 변경 내용

### 1. Window.h — ResizeCallback 훅 추가

```cpp
// public:

using ResizeCallback = std::function<void(Math::ivec2)>;

void SetResizeCallback(ResizeCallback callback);



// private:

ResizeCallback m_resize_callback;
```

### 2. Window.cpp — SIZE_CHANGED 이후 callback 호출

```cpp
case SDL_WINDOWEVENT_SIZE_CHANGED:

    SDL_GL_GetDrawableSize(sdl_window, &window_size.x, &window_size.y);

    GL::Viewport(0, 0, window_size.x, window_size.y);

    if (m_resize_callback) m_resize_callback({ window_size.x, window_size.y });

    break;



// SetResizeCallback 구현 추가:

void Window::SetResizeCallback(ResizeCallback callback)

{

    m_resize_callback = std::move(callback);

}
```

### 3. Settings.h — 정적 멤버 추가

```cpp
static Math::ivec2 s_window_size;   // default { 1600, 900 }

static void LoadUserSettings();

static void SaveUserSettings();
```

### 4. Settings.cpp — load/save 구현

저장 경로: `"user_settings.json"` (실행 파일과 같은 디렉토리)

nlohmann/json include: `"Game/DragonicTactics/External/json.hpp"`

```cpp
Math::ivec2 Settings::s_window_size = { 1600, 900 };



void Settings::LoadUserSettings()

{

    try {

        std::ifstream f("user_settings.json");

        if (!f.is_open()) return;

        auto j = nlohmann::json::parse(f);

        s_window_size.x  = j.value("window_width",   1600);

        s_window_size.y  = j.value("window_height",  900);

        s_bgm_enabled    = j.value("bgm_enabled",    true);

        s_bgm_volume_pct = j.value("bgm_volume_pct", 100);

        ApplyBGMSettings();

    } catch (...) {}

}



void Settings::SaveUserSettings()

{

    try {

        nlohmann::json j;

        j["window_width"]   = s_window_size.x;

        j["window_height"]  = s_window_size.y;

        j["bgm_enabled"]    = s_bgm_enabled;

        j["bgm_volume_pct"] = s_bgm_volume_pct;

        std::ofstream f("user_settings.json");

        f << j.dump(2);

    } catch (...) {}

}
```

또한 `SelectOption()`의 BGMToggle·BGMVolume 분기에 `SaveUserSettings()` 호출 추가.

### 5. main.cpp — 시작 시 로드 + resize callback 등록

```cpp
#include "Game/Settings.h"   // 추가



int main(...)

{

    Engine& engine = Engine::Instance();

    engine.Start("Dragonic Tactics");



    // 저장된 설정 로드 및 창 크기 적용

    Settings::LoadUserSettings();

    Engine::GetWindow().ForceResize(Settings::s_window_size.x, Settings::s_window_size.y);



    // 리사이즈 시 자동 저장

    Engine::GetWindow().SetResizeCallback([](Math::ivec2 new_size) {

        Settings::s_window_size = new_size;

        Settings::SaveUserSettings();

    });



    engine.GetGameStateManager().PushState<Splash>();

    // ... 기존 루프 코드

}
```

### 6. MainMenu.cpp — ForceResize를 saved size 기준으로 변경

```cpp
// Before

Engine::GetWindow().ForceResize(default_window_size.x, default_window_size.y);



// After — 저장된 크기로 복원 (첫 실행 시 기본값 1600×900)

Engine::GetWindow().ForceResize(Settings::s_window_size.x, Settings::s_window_size.y);
```

## 검증

1. 앱 실행 → 창을 전체화면으로 변경 → `user_settings.json` 생성/갱신 확인

2. 앱 재시작 → 이전 창 크기로 복원되는지 확인

3. 인게임 중 창 리사이즈 → `user_settings.json` 갱신 확인

4. Settings에서 BGM Off → 재시작 후에도 Off 유지 확인

5. 메인메뉴·세팅·인게임 모두 동일한 창 크기 사용 확인
